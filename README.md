# MIMI Beauty Club — Demo v3 · Christmas Nail Edit

Demo conceptual de una web premium/playful para un estudio de belleza con:

- Manicura, pedicura, cejas y pestañas.
- Campaña estacional Christmas Nail Edit.
- Galería editorial más visual y compacta, inspirada en nail art navideño maximalista.
- Reserva online con selección de servicio, fecha y hora.
- Extras de manicura: pedrería, dibujo personalizado, cat eye, chrome/glazed, nail art navideño y alargamiento.
- Cálculo dinámico del precio según extras.
- Pantalla de pago de demostración con señal de 10 €.
- Confirmación de reserva simulada.
- Diseño responsive y CTA de reserva fijo en móvil.

## Importante sobre las imágenes

Las imágenes de esta versión se han incorporado como referencias visuales proporcionadas para el prototipo. Antes de publicar el proyecto como portfolio o utilizarlo para un cliente, conviene sustituir cualquier imagen de procedencia externa por fotografías propias, de stock con licencia adecuada o generadas expresamente.

## Pago real

El pago es únicamente una simulación frontend. Para una versión real se podría conectar Stripe Checkout o una plataforma de reservas. Nunca deben incluirse claves secretas de pago dentro de `script.js` o de cualquier archivo frontend.

## Abrir localmente

Abre `index.html` en VS Code y utiliza Live Server si quieres previsualizarlo en navegador.
